# Origem dos procedimentos

Cópia efetuada em 05/11/2026 do pacote reutilizável `procedimentos-orcamento`, do repositório [orcamento-obras](https://github.com/LucasAbreu89/orcamento-obras).

A origem é o working tree atual, com base no commit `869ae1dd2db98f0526d7f60f373b8e7d06591c3b`. Foram preservadas também as alterações locais atuais nas referências de áreas e de quantitativos/memórias; o repositório de origem não foi alterado para produzir esta cópia.

Os 18 arquivos foram copiados integralmente e conferidos por SHA-256. Os valores de cada arquivo estão em [procedimentos-manifesto.json](procedimentos-manifesto.json). Não foram copiados projetos, planilhas, prints ou dados de obras/clientes.

O pacote é conhecimento e procedimento operacional: não é um motor de CAD/IA pronto. A adaptação para contratos de ferramentas, cálculo e execução por API está especificada no PRD. Exemplos de uma obra não definem dimensões ou premissas universais.
